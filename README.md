# Журнал оценок студентов

Простое консольное приложение для ведения журнала оценок студентов, написанное на Go.

## Функциональность.
- 📋 Просмотр всего журнала студентов
- ➕ Добавление новых студентов (с фамилией, именем и отчеством)
- 📝 Добавление оценок студентам
- ❌ Удаление студентов из журнала
- 📊 Автоматический расчет среднего балла

### Запуск приложения.
1. Сохраните все 4 файла.
2. Поместите их в 1 папку.
3. Запустите программу командой:
go run .

## Использование.
### Главное меню.
При запуске отображается основное меню:
 Журнал оценок
1. Посмотреть журнал
2. Добавить студента
3. Добавить оценку студенту
4. Удалить студента
5. Выйти
Выберите действие:

#### 1. Просмотр журнала - Показывает полный список студентов. 

 Журнал студентов
1. Студент: Иванов Петр Сергеевич
   Оценки: [5 4 5]
   Средний балл: 4.67

2. Студент: Сидорова Анна Владимировна
   Оценки: [3 4 5 4]
   Средний балл: 4.00
   
#### 2. Добавление студента.

Процесс добавления нового студента:
- Ввод фамилии
- Ввод имени
- Ввод отчества

#### 3. Добавление оценки.

- Выбор студента из списка по номеру
- Ввод оценки от 2 до 5

#### 4. Удаление студента.

- Выбор студента для удаления по номеру
- Подтверждение удаления

### Структура данных.

Студент (Student)
type Student struct {
    FirstName  string  - Имя
    MiddleName string  - Отчество
    LastName   string  - Фамилия
    Grades     []int   - Оценки
}

### Основные методы.

- CalculateAverage() - расчет среднего балла
- AddGrade(grade int) - добавление оценки
- DisplayInfo() - вывод информации о студенте

### Допустимые оценки.

2 - Неудовлетворительно
3 - Удовлетворительнo
4 - Хорошо
5 - Отлично
