# Журнал оценок студентов

Простое консольное приложение для ведения журнала оценок студентов, написанное на Go.

## Функциональность

- 📋 Просмотр всего журнала студентов
- ➕ Добавление новых студентов (с фамилией, именем и отчеством)
- 📝 Добавление оценок студентам
- ❌ Удаление студентов из журнала
- 📊 Автоматический расчет среднего балла

### Запуск приложения

1. Сохраните папку "журнал".
2. Запустите программу командой:
